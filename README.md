# 🧭 COMPASS — Fortnite Token Detector

**COMPASS** is a Fortnite match analysis tool designed to help players identify chest locations and determine which chest contains the Token during a match.

Built for fast analysis and an intuitive experience, COMPASS aims to make in-game chest identification easier and more efficient.

## ✨ Features

- 🧭 **Chest Detection** — Identify chest locations during a Fortnite match.
- 🔍 **Token Identification** — Highlight the chest associated with the Token.
- 📍 **Visual Tracking** — Display relevant chest locations for easier navigation.
- ⚡ **Real-Time Analysis** — Designed for quick in-match information processing.
- 🎨 **Clean Interface** — Simple and intuitive user experience.
- 🚀 **Lightweight Design** — Focused on performance and usability.

 
1. Launch Fortnite.
2. Start a match.
3. Launch COMPASS.
4. Analyze available chest information.
5. Identify the chest marked as containing the Token.

## 🛠️ Project Goals

- Improve chest information visualization.
- Simplify Token identification.
- Provide a clear and accessible interface.
- Explore Fortnite match data analysis.
